# Procedural RA2/YR rendering

RTSMerge now follows the Conda-RTS visual approach: unit visuals are generated at runtime instead of depending on proprietary RA2/YR art files.

The Spring engine still needs a technical model reference for a UnitDef. The procedural renderer therefore uses one tiny non-visual 3DO placeholder generated by `tools/generate_procedural_placeholder.py`. LuaUI intercepts `DrawUnit`, suppresses that placeholder, and draws faction-specific geometry with Lua OpenGL primitives.

Implemented runtime archetypes include:
- Allied/Soviet/Yuri tanks
- MCVs and harvesters
- infantry, heroes, engineers and spies
- aircraft and helicopters
- naval units
- major structures

The roster is data-driven through `customParams.ra2_visual`. The renderer is the visible representation; the placeholder is only an engine compatibility shim.
