# Model conversion contract

RTSMerge does not commit proprietary source art. A legally owned RA2/YR installation is converted locally into Spring-compatible assets.

Expected output:
- objects3d/*.3do or another model format supported by the selected Spring runtime
- textures in the corresponding Spring texture locations
- unit definitions referencing the converted model by objectname

Before a unit can enter the playable roster, its converted model must exist and pass the model manifest/validation tools.
