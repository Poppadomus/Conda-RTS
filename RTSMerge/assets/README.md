# C&C asset integration

RTSMerge can use original Command & Conquer asset formats when the user supplies assets they are licensed to use.

Expected local source files include Tiberian Dawn MIX archives such as CONQUER.MIX, GENERAL.MIX, LOCAL.MIX / CCLOCAL.MIX, theater MIX archives, and optionally SOUNDS.MIX / SPEECH.MIX.

These are intentionally not bundled in this repository.

Target pipeline: MIX -> SHP/PAL/TMP -> Spring-compatible textures and definitions.
